# Jar-of-Hope

On-chain wish board with community voting and tipping, built on BOT Chain mainnet.

## Features
- Post a wish (pay small BOT fee)
- Vote on wishes (1 wallet = 1 vote)
- Tip the wisher directly with BOT
- see list of wishes from the wish board page
- use night mode or day mode
- see trending wishes and top tipper on leaderboard page
